# 可调整尺寸的文章详情面板设计

## 目标

在首页的“详情居中”阅读布局中，允许用户自由调整文章详情面板的宽度和高度，以适应不同阅读与列表浏览偏好。

## 交互

仅当视口宽度大于 860px 且阅读布局为“详情居中”时显示两个拖拽手柄：

- 详情右边缘的垂直手柄调整详情宽度；文章列表占用剩余宽度。
- 详情底边的水平手柄调整详情高度；文章列表保持阅读区域高度。

鼠标和触控指针均可拖拽。拖拽过程中禁用文本选择，并使用指针捕获保证光标移出手柄后仍能完成调整。

## 尺寸与持久化

宽度按阅读区域可用宽度的百分比保存，限定在 40% 至 75% 之间。高度按像素保存，限定在 280px 至当前视口可用高度之间；窗口大小变化后会重新限制该值。

宽高使用独立 localStorage 键保存。无效、缺失或无法访问存储时使用当前详情居中布局的默认尺寸，且不会阻断页面渲染或本次拖拽。

## 响应式行为

默认布局不显示拖拽手柄，也不应用详情居中布局的尺寸偏好。窄屏（不大于 860px）保持现有上下排列并隐藏手柄；用户回到桌面“详情居中”布局后，恢复之前保存的尺寸偏好。

## 实现结构

新增独立的尺寸偏好工具模块，定义尺寸类型、默认值、读取、保存和边界限制函数。`Home` 维护临时尺寸状态和拖拽生命周期，将最终尺寸写入 CSS 自定义属性。CSS 仅在详情居中桌面模式读取这些属性并显示手柄，避免影响既有默认与移动端布局。

## 测试

- 尺寸工具：默认回退、无效值、边界限制、受限存储以及保存恢复。
- 首页：详情居中时显示两个手柄；默认布局和窄屏不显示；拖拽更新详情尺寸并持久化；尺寸不会越过限制。

## 范围

只修改 Web 首页、相关样式、尺寸偏好工具和测试。不改动后端 API、数据库或 SQL 查询。
