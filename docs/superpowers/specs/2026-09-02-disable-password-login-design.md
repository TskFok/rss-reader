# 关闭账号密码登录设计

## 目标

超级管理员可在「我的」页关闭全站账号密码登录。关闭后：

- 所有人只能使用飞书登录
- 用户名密码注册入口与注册 API 一并关闭
- 不校验飞书登录是否已配置或可用

默认开启账号密码登录，与现有行为一致。开关可再次打开，恢复密码登录与注册。

## 数据模型

新增 `app_settings` 表，作为单行站点配置：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint | 主键，固定使用 `1` |
| `password_login_enabled` | bool | 是否允许账号密码登录与注册，默认 `true` |
| `created_at` / `updated_at` | time | 常规时间戳 |

首次读取时若不存在记录，则插入 `id=1` 且 `password_login_enabled=true`。不写入 `config.yaml`。

## 接口

### 公开：登录方式

`GET /api/auth/login-options`

无需认证。响应：

```json
{ "password_login_enabled": true }
```

登录页与注册页用该接口决定是否展示账号密码与注册入口。Android 客户端同样可读此接口。

### 当前用户设置

扩展现有 `GET /api/users/me/settings` 与 `PUT /api/users/me/settings`，增加字段 `password_login_enabled`。

- 所有已登录用户可读该字段
- 仅超级管理员可写入；普通用户 PUT 该字段时返回 `403`，错误为「需要超级管理员权限」，其它个人设置字段仍可照常更新
- 关闭前不探测飞书配置

### 登录与注册拒绝

当 `password_login_enabled` 为 `false`：

- `POST /api/auth/login` 返回 `403`，错误为「已关闭账号密码登录，请使用飞书登录」。在校验用户名密码之前拒绝，避免无用计算
- `POST /api/auth/register` 返回 `403`，错误为「已关闭账号注册，请使用飞书登录」

飞书登录、换票、已签发 JWT 均不受影响。已登录会话继续有效，直到 JWT 过期或用户主动退出。

## 界面

### 「我的」页

仅超级管理员看到该设置行，放在「登录状态」上方，样式与现有设置行一致：

- 标题：账号密码登录
- 说明：关闭后全站只能使用飞书登录和注册
- 右侧按钮在「已开启」与「已关闭」之间切换，表示当前全站状态

点击关闭时先弹出确认框，说明会同时关闭注册，且不会检查飞书是否可用。确认后立即保存。开启不需要确认。保存过程中按钮禁用；失败时保持原状态并提示错误。普通用户不显示该行。

### 登录页

读取 `GET /api/auth/login-options`：

- 开启：保持现有账号密码 Tab、飞书 Tab 与注册链接
- 关闭：只保留飞书登录，隐藏账号密码 Tab 和「还没有账号？注册」

### 注册页

关闭时访问 `/register` 重定向到 `/login`，并提示「已关闭账号注册，请使用飞书登录」。

## 文档

`docs/openapi.yaml` 与 `docs/ANDROID_REST_API.md` 补充：

- `GET /api/auth/login-options`
- 登录、注册在关闭时的 `403` 及错误文案
- 设置接口的 `password_login_enabled` 字段及超管写入限制

## 测试

后端：

- 默认 `password_login_enabled=true`
- 超级管理员可关闭与重新开启
- 普通用户不能修改该字段
- 关闭后 login、register 返回约定 `403` 文案
- `GET /api/auth/login-options` 反映当前值

前端：

- 「我的」页仅超级管理员看到开关
- 确认关闭后调用更新接口
- 登录页按开关隐藏密码 Tab 与注册入口
- 注册页在关闭时跳转登录页
- 开关为开启时，现有登录、注册、「我的」页测试仍通过

## 范围

包含：`app_settings` 表、上述 API、登录/注册/「我的」页、对应单元测试与 API 文档。

不包含：飞书可用性探测、按用户关闭密码登录、使已签发 JWT 立即失效、从 `config.yaml` 读取该开关。
