# 首页阅读布局切换设计

## 目标

首页阅读区域提供两种可切换布局：

- **默认布局**：保持现有顺序——订阅栏、文章列表、内容详情。
- **详情居中**：订阅栏保持左侧，内容详情移至中间且获得更宽阅读区域，文章列表位于右侧。

首次访问及没有有效偏好时必须使用默认布局，确保现有用户体验不变。

## 交互与持久化

在首页筛选栏增加带有无障碍名称“阅读布局”的下拉选择：

- `默认布局`
- `详情居中`

选择即时生效，并写入 `localStorage`。页面重新挂载或刷新后从该存储值恢复选择；存储不存在、存储不可用或值无效时回退为默认布局。布局偏好不写入 URL，不影响可分享的订阅、已读筛选与分类折叠状态。

## 实现结构

新增独立的 `homeLayout` 工具模块，集中定义布局联合类型、默认值以及读取/保存偏好的函数，避免在 `Home` 页面内分散直接访问 `localStorage`。

`Home` 持有当前布局状态，并在根节点增加表达当前布局的 CSS 类：

- 默认：`.home-layout`
- 详情居中：`.home-layout.home-layout--detail-centered`

为文章列表与详情面板增加一个只负责布局的 `.home-reading-panels` 容器。默认布局维持该容器的上下排列；详情居中布局将它改为横向排列，并通过 `order` 调整详情面板与文章列表的视觉顺序和宽度。`ArticleList` 与详情内容本身不重挂载，现有滚动、加载、键盘导航和详情缓存逻辑都不受影响。

## 响应式与错误处理

现有窄屏断点下首页会纵向堆叠。详情居中布局在该断点下不调整顺序或宽度，保持当前移动端阅读顺序与行为。

所有 `localStorage` 访问均受运行环境与异常保护，避免隐私模式或浏览器限制影响首页渲染。

## 测试

新增工具模块单元测试，覆盖：

- 缺失或无效存储值时读取默认布局；
- 保存选项后写入预期键和值。

扩展首页测试，覆盖：

- 初始渲染使用默认布局；
- 选择“详情居中”后根节点拥有对应布局类，并持久化该选择；
- 重渲染时从已保存的选择恢复详情居中布局。

## 范围

仅修改 Web 首页、相关样式、布局偏好工具及其测试。不会改动后端 API、数据库或 SQL 查询。
