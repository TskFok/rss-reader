# 原始网页图标按钮设计

## 目标

缩小条目详情操作区中「查看原始网页」和「返回正文」控制的横向占用，同时保持操作含义清晰可访问。

## 方案

- 将当前文字按钮替换为内联 SVG 网页图标按钮，不使用 Unicode 表情，确保不同平台视觉一致。
- 处于 RSS 正文视图时，使用网页图标，`aria-label` 与 `title` 均为「查看原始网页」。
- 处于原始网页视图时，使用返回正文的图标，`aria-label` 与 `title` 均为「返回正文」。
- 按钮仍位于「手动 AI」左侧，保留现有切换行为、键盘可操作性、聚焦样式和测试覆盖。
- 将原始网页按钮使用独立 CSS 类，设置正方形紧凑尺寸；手动 AI 仍保留现有文字按钮样式。

## 测试

- 首页和收藏页测试验证图标按钮的可访问名称会随视图在「查看原始网页」和「返回正文」之间切换。
- 验证图标按钮仍排在「手动 AI」之前，且既有 iframe 与返回正文交互保持不变。
